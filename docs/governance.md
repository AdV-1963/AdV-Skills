# Gobierno de AdV Skills

## Fuente y función

Este repositorio es la fuente versionada de las skills propias de AdV. No sustituye Obsidian como sistema de conocimiento ni Dropbox como archivo documental.

## Criterios

- Una skill por flujo acotado y repetible.
- Evitar skills solapadas.
- No almacenar estado de proyectos, casos o expedientes dentro de una skill.
- No introducir material de TRC.
- Mantener instrucciones compactas y desplazar detalle a `references/` solo cuando sea necesario.
- Probar cambios antes de considerarlos vigentes.
- Mantener trazabilidad mediante commits.

## Pendiente de validación

La política formal de versiones y publicación en marketplace se definirá cuando se monte el marketplace de ChatGPT.

# Skills

Cada subcarpeta representa una única skill instalable.

Estructura mínima:

```text
nombre-skill/
├── SKILL.md
└── agents/
    └── openai.yaml
```

Estructura ampliada cuando sea necesaria:

```text
nombre-skill/
├── SKILL.md
├── agents/
│   └── openai.yaml
├── references/
├── scripts/
└── assets/
```

No crear carpetas auxiliares si no aportan utilidad real.
